# Power-BI-Employee-Attrition-Analysis-Project
The analysis shows that attrition is higher among specific job roles, lower job levels, employees in medium-sized companies, and varies significantly by gender due to work-life balance and salary factors.

| Tool | Usage |
|--------|--------|
| Power BI | Dashboard & Visuals |
| Power Query | Data Cleaning & ETL |
| DAX | Calculations & Measures |
| Excel/CSV | Source Data |
